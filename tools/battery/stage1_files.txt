# The release battery's stage-1 curated list.
#
# WHAT THIS IS
#   The set of test files the release battery runs as its stage-1 leg:
#   CPU-only (GPUWM_NO_LOCAL_GPU=1), fast enough to run on every cut, and
#   chosen to cover the paths a release most often breaks.  It is a
#   CURATED list, not a discovered one -- `pytest tests/` is a different,
#   much longer job, and stage 1 exists precisely because it is short.
#
# WHO CONSUMES IT
#   The per-assembly queue scripts (scratchpad q<NNN>_legs.ps1, "LEG S1").
#   Their $stage1 array is GENERATED from this file, not retyped:
#
#     $stage1 = @(Get-Content (Join-Path $CUT 'tools/battery/stage1_files.txt') |
#         ForEach-Object { $_.Trim() } | Where-Object { $_ -and -not $_.StartsWith('#') })
#
#   This header used to point at scratchpad q_TEMPLATE_stage1.ps1 for the
#   full leg.  That file is gone from every machine -- the same failure
#   this list closes (task #122), one level up.  Before this file existed
#   the list lived ONLY in those scratchpad scripts and was propagated by
#   copy from one assembly to the next; a lost scratchpad silently lost
#   every amendment ever made to it.
#
#   BEFORE RUNNING THE LEG
#   The battery runs in a throwaway worktree, which carries no build
#   output, so the rust binaries every real-artifact suite drives are
#   absent -- and those suites SKIP rather than fail, so the leg
#   goes green with the rust half of the product untested.  Stage the
#   binaries first, and let the script prove they took:
#
#     pwsh -File tools/battery/provision_stage1.ps1
#
# FORMAT
#   One repository-relative path per line, forward slashes.  Blank lines
#   and lines whose first non-space character is `#` are ignored.  Order
#   is the order the battery runs them and is append-only by convention,
#   so the amendment history stays legible.
#
# AMENDMENT DISCIPLINE
#   An addition carries its REASON inline, on the line above it, naming
#   the task or the incident that earned the entry.  A removal is not a
#   tidy-up: say why the coverage is no longer needed, in the commit.
#   tests/test_stage1_manifest.py is the gate -- it checks every path
#   exists, rejects duplicates, and pins the two entries whose absence
#   caused a real miss.
