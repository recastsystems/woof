# Stage 1 files whose CPU rows require compiled native artifacts.
# Linux runs every Stage 1 entry and builds the native libraries first.
# Windows runs the remaining Stage 1 entries plus all publication/CI controls;
# its separate native Rust job tests the declared Cargo packages on Windows.
# This is a platform partition, not a skip budget. Every row must remain in
# stage1_files.txt and in the Linux selection. Each row names its dependency.
#
# A native-dependent file missing from this list passes the private Linux
# gate, where every native is built, and fails only on the public Windows
# runner (public CI 37665304517 at 2.8.7: 81 failures and 19 errors in 12
# files). The release battery catches that on Linux with
#   python tools/battery/emulate_windows_cpu_partition.py --work-dir <scratch>/winpart
# which runs the Windows selection of Stage 1 from a fresh clone and virtual
# environment with every GPUWM_* variable cleared and HOME empty, so no
# native artifact is reachable but the table fetcher (rw_fetch, built outside
# the tree and named by WOOF_RW_FETCH), the one native the Windows cpu job
# builds, because every staged table is pin-checked through it. A row that
# needs only rw_fetch therefore stays off this list and runs on Windows.
# It is not a Stage 1 entry (it runs Stage 1);
# the integrator runs it on the candidate beside the Stage 1 leg and requires
# 0 failures.
