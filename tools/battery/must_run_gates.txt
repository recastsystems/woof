# Runner: tools/battery/no_silent_skip.py, registered by default from
# tests/conftest.py and available to any leg as
#
#     python -m pytest -p tools.battery.no_silent_skip <files...>
#
# Static gate: tests/test_must_run_gates.py.
#
# WHY THIS LIST EXISTS
# --------------------
# tools/battery/no_silent_deselection.py and tools/battery/list_census.json
# count COLLECTED items, and a skipped item is collected.  So a deck whose
# every test skips contributes its full count to the census, clears its floor,
# and the leg is green.  The tree's own worked example, at this commit:
# tools/rrtmg_wrf461_oracle/lw_gate.py:23-26 defaults its fixture root to
# one agent job's scratch directory on one machine -- and tests/test_rrtmg_lw_numpy.py:38 is a
# whole-module skipif on that directory existing.  It exists in no clone, so
# every RRTMG longwave bitwise gate skips everywhere, inside a module whose
# own line 92 reads "this gate must never silently skip again".
#
# Every file below reads fixtures that are COMMITTED TO THIS REPOSITORY
# (woof/data/*/oracle, tools/*_wrf461_oracle/, tests/data/), so there is no
# environment to blame: if it skips, coverage left.  Measured at a70ade37,
# each entry carries no cupy import, no pytest.skip, no skipif and no
# importorskip, and each module executes its module scope on a bare CPU box.
#
# FORMAT
#   tests/test_x.py                 a skip is a failure (ceiling 0)
#   tests/test_x.py  skips<=N       at most N tests may skip
#   tests/test_x.py  skips<=*  # why   the count is a property of the fixture
#                                      data, not a constant; the entirely-
#                                      skipped arm still applies.  The reason
#                                      comment is required by
#                                      tests/test_must_run_gates.py.
#
# ADDING an entry is cheap and is how a new committed-fixture deck becomes
# binding.  REMOVING one is a claim that the deck's fixtures stopped shipping;
# say so in the commit.
